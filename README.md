Il sito di Rivela: siti web, presentazioni, dossier e video con IA per aziende e attività locali.

Questa è la versione aggiornata del 29 ottobre 2026, dedicata soltanto a Rivela.

- Home, Servizi e selezione di alcuni progetti, Come funziona e prezzi, Vantaggi, Contatti.

## Pubblicazione

Sito statico HTML, CSS e JavaScript: non serve compilare il progetto.

- **GitHub Pages:** branch `main`, cartella `/ (root)`.
- **Altri hosting statici:** cartella del sito alla radice del repository, nessun comando di build.
- **Dominio personale:** configurarlo nelle impostazioni dell'hosting scelto e poi nel pannello DNS del dominio. Nessun dominio è stato inserito in questo repository.

Gli asset sono in `images/`. I nomi `laip.css` e `laip.js` sono mantenuti come nomi interni dei file condivisi.

Il repository non comprende altre bozze, progetti sportivi, dati di accesso o file temporanei di lavoro.
